# 🤖 @SoyJose11Bot - Telegram Bot with TTS & Translation

A Telegram bot that provides Text-to-Speech and Translation services.

## 🚀 Features

- 🔊 **Text-to-Speech**: Convert any text to natural-sounding speech
- 🌍 **Translator**: Translate text between multiple languages
- 💬 **Easy to use**: Simple commands and clear instructions

## 📋 Commands

- `/start` - Welcome message and features overview
- `/tts` - Convert text to speech
- `/translate` - Translate text
- `/help` - Usage instructions

## 🔧 Setup
